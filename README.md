# 💻 BryTech

## 📖 Overview

**BryTech** is a web project I submitted during the 2nd Quarter Web Development project at **Dr. Yanga's Colleges, Inc.**, where it received the highest and preferred score from my teacher.

The website is a showcase of computer parts and brands, combining visual appeal with interactive design. It integrates the **Google Gemini API** and uses raw JSON files to display collected images and information. The content was compiled with the help of **ChatGPT**, focusing on a polished user experience rather than complex functionality.

---

## 🎯 Purpose

The main goal of this project is to:

- Present computer hardware and brands in an organized and visually appealing manner  
- Demonstrate UI/UX skills through interactive animations and layout design  
- Showcase knowledge in integrating APIs and handling JSON data  
- Practice web development techniques learned in class  

---

## 🛠️ Technologies Used

This project was built using:

- **HTML, CSS & JavaScript** – for structure, styling, and interactivity  
- **Google Gemini API** – for AI-based content integration  
- **JSON** – for storing and displaying images of computer parts  
- **Animations & UI Design** – to create an engaging and modern interface  

The emphasis of this project was on **visual design and smooth animations**, making the website both appealing and interactive.
